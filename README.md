# Praktikum JavaScript Dasar — Modul Praktikum 07

## Isi folder
- `index.html`: halaman latihan dan mini-proyek.
- `style.css`: tampilan halaman.
- `script.js`: logika JavaScript untuk latihan.

## Cara menjalankan
1. Ekstrak folder `praktikum-js-dasar`.
2. Buka `index.html` menggunakan browser.
3. Tekan tombol-tombol pada tiap bagian untuk menjalankan latihan.
4. Untuk latihan Console, buka Developer Tools → Console (umumnya tekan F12).
5. Tidak memerlukan instalasi library atau koneksi internet.

## Kesesuaian dengan modul
Implementasi mencakup Praktik 1–17, mini-proyek Kalkulator Belanja, Tantangan B (Daftar Produk), Tantangan C (Formulir Pemesanan), serta jawaban Evaluasi Pemahaman. Ketentuan utama mini-proyek mengikuti modul: diskon 10% jika subtotal minimal Rp100.000, input wajib diperiksa, harga tidak negatif, dan jumlah minimal 1.

## Catatan pengujian mini-proyek
- Harga 20.000, jumlah 2 → subtotal Rp40.000, diskon Rp0, total Rp40.000.
- Harga 50.000, jumlah 2 → subtotal Rp100.000, diskon Rp10.000, total Rp90.000.
- Nama kosong → pesan semua kolom wajib diisi.
- Jumlah 0 → pesan harga/jumlah tidak valid.
- Harga -5.000 → pesan harga/jumlah tidak valid.
