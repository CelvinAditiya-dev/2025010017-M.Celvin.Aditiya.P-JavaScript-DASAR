Evaluasi Pemahaman

      
    
        
  1. Perbedaan HTML, CSS, dan JavaScript: HTML membangun struktur konten, CSS mengatur tampilan, sedangkan JavaScript mengolah data dan menambahkan perilaku/interaksi.
    2. 
        
  2. Perbedaan let dan const: let digunakan jika nilai variabel akan diubah; const digunakan jika variabel tidak akan diberi nilai ulang.
    3. 
        
  3. Mengapa prompt() perlu dikonversi? Nilai dari prompt() berupa string, sehingga perlu dikonversi dengan Number() sebelum perhitungan numerik.
    4. 
        
  4. Perbedaan = dan ===: = memberikan nilai ke variabel, sedangkan === membandingkan nilai dan tipe data secara ketat.
    5. 
        
  5. Kapan for cocok digunakan? Ketika jumlah pengulangan atau penghitungnya dapat ditentukan, misalnya mencetak angka 1 sampai 10.
    6. 
        
  6. Manfaat fungsi dan return: Fungsi mengelompokkan instruksi agar dapat digunakan kembali. return mengembalikan hasil dari fungsi kepada pemanggilnya.
    7. 
        
  7. Apa itu DOM? DOM adalah representasi dokumen HTML yang dapat diakses JavaScript untuk memilih dan mengubah elemen.
    8. 
        
  8. Apa itu event listener? Mekanisme untuk menangani kejadian pengguna, misalnya addEventListener("click", ...) menjalankan fungsi ketika tombol diklik.
    9. 
        
  9. Mengapa validasi diperlukan? Untuk mencegah data kosong atau tidak sesuai diproses dan memberikan pesan kesalahan yang jelas.
    10. 
        
  10. Bagaimana memeriksa kesalahan JavaScript? Buka Developer Tools pada browser, pilih tab Console, baca kesalahan pertama, lalu periksa sintaks, nama variabel, ID elemen, dan nilai input.
